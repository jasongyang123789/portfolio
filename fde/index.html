01　代表项目

两个 AI 作品，都来自真实的管理痛点

它们不炫技术——没有接大语言模型，因为企业内部数据需要的是准确与可追溯。 需求来自我每天的日常工作，方案由我独立完成设计与落地，下面是可交互的完整版本。

WORK 01
战略材料知识库 · 智能问答

痛点：209 份、2,310 万字符战略材料，「材料都在，但要翻半天」。
方案：四层知识结构（公司战略 / 业务产品 / 职能制度 / 专题管控）+ 检索增强问答， 返回「结论 → 依据要点 → 关键数据 → 引用来源（含相关度打分）」，每条结论可追溯到具体材料片段。
取舍：不接大语言模型——企业内部数据要的是准确与可追溯，防编造优先于生成流畅。

04　能力结构

落地型能力的四件事

Ⅰ需求识别与方案设计

6 年业务一线（汽车零部件、医疗器械）：从日常流程里识别真实痛点，判断「值不值得做」；方案设计含数据来源、结构化方式、防编造约束、验收指标，先算 ROI 再动手。

ⅡRAG 与知识工程

知识库分层结构（战略 / 产品 / 制度 / 专题）、引用溯源与相关度打分、防编造与无答案处理；输出可追溯的「结论—依据—数据—来源」四段式回答，适配企业内网无大模型依赖的场景。

Ⅲ工作流与 Agent 编排

多节点工作流编排：数据接入 → 口径校验 → 计算 → 风险判定 → 异常归因 → 报告生成；异常分级与建议动作自动生成，支持 Excel 导出与 API 数据源，嵌入既有业务流程。

Ⅳ落地交付与价值量化

工具迁就流程：优先复用现有 Excel / OA 习惯，降低使用门槛；每个产品都能给出提效数字（人工 2 天 → 5 秒、翻材料 → 随问随答），并用使用率与反馈持续迭代。
